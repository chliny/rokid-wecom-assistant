# 本地二维码扫码模拟预览

在项目根目录执行 `npm run preview:qr`，浏览器打开终端打印的本机地址。预览来自当前 `app` 的 `aix preview` HTML，修改源码后需停止并重新启动预览。

1. 在页面顶部选择二维码图片；可一次选多张，按文件选择器返回的顺序逐张扫描，也可每次选一张。重新选择会替换尚未扫描的队列，“清空图片”丢弃队列。
2. 在原应用首页用预览自带的确认键进入扫码页，再按确认键扫描一张；分片时继续逐张按确认，按应用页面的进度提示操作。应用的其他按键行为不变。
3. 结束后关闭页面并在终端按 Ctrl+C 停止服务。

图片只在当前浏览器页面内存中读取，预览服务不接收图片；服务仅监听 127.0.0.1，地址包含随机令牌，请勿分享。二维码和地址仍可能出现在浏览器历史、调试信息或本地文件中；勿上传截图、日志和真实二维码。应用如果选择持久保存，浏览器站点数据可能保留配置，用后请清除该站点数据。扫码完成后应用会按原流程真实连接二维码中的 MCP 服务，可能发送凭据；只使用可信配置，不等同于离线网络模拟。此工具只模拟拍照，不模拟设备摄像头或保证其他硬件能力可用。

页面运行依赖本机安装的 `@yodaos-pkg/ink`，不从 CDN 加载 Ink。预览不包含二维码识别器，需要浏览器原生支持 `BarcodeDetector` 和 `qr_code` 格式；缺少该能力时无法使用图片扫码。文件选择的顺序由浏览器及操作系统决定；如果顺序不确定，请每次选一张。识别失败时，重新选择对应图片再按确认重试。
